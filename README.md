
# Centralised Study of the Selective Multi-Head Attention (SMHA)

This codebase includes SMHA definition (`model.py`), SMHA-related metrics (`attention_head_similarity.py`) and the main training loop, calculating statistics (`train.py`). The experiments can be run directly using the slurm scheduler scripts.


## About

This codebase is based on the original nanoGPT project and was modified by Andrzej Szablewski during his dissertation project on _Improving Compute Efficiency in Federated LLM Training with Heterogeneous Clients_. To inspect changes, run `git diff master split-attn`.
